## Enterprise Network Topology with VLAN & Cisco ASA Hardware Firewall

## 📌 Project Overview
Designed and deployed an enterprise-level network topology utilizing Cisco equipment, implementing VLAN segmentation for optimal data flow and department isolation, and integrating a Cisco ASA hardware firewall for robust security enforcement and access control.

## 🛠️ Technologies & Tools
* Cisco Routers & Switches
* Cisco ASA Hardware Firewall
* VLAN, Subnetting, Routing
* Cisco Packet Tracer / GNS3-VM

## ⚙️ Key Configurations & Implementation
* **VLAN Segmentation:** Configured multiple VLANs to segregate internal departments and control broadcast domains.
* **Firewall Security:** Integrated Cisco ASA hardware firewall to establish access control lists (ACLs) and security policies, protecting the internal network from potential threats.
